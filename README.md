

\# AideaInventoryMng



\## 概要

ASP.NET Core Web APIとPostgreSQLを使用した商品管理システムです。



\## 開発環境

\- OS: Windows 11

\- IDE: Visual Studio 2026

\- Language: C#

\- Framework: ASP.NET Core / .NET 10

\- Database: PostgreSQL 18

\- ORM: Entity Framework Core 10

\- API Documentation: Swagger / OpenAPI



\## 開発目的

C#の既存業務経験をベースに、ASP.NET CoreによるWeb API開発とPostgreSQLを利用したデータベース連携およびAWSを習得する。



\## 開発予定機能

\- 商品一覧取得

\- 商品詳細取得

\- 商品登録

\- 商品更新

\- 商品削除

\- 商品検索
